How to use the map manager

                
Most updates follow the same four-step workflow.

            

            
        

        

            

                
1
Choose a country
Select an existing map on the left, or add a new country with its SVG.

                
2
Add or update hotspots
Import the standard Excel file or add a hotspot manually. Review anything shown in yellow or red.

                
3
Add photos and check the map
Drop photos onto each hotspot. Use the map editor to confirm marker positions and provinces.

                
4
Check issues, review, then apply
Validate the current country as you work, use Issues for the project-wide view, then review and apply the file changes.

            

            

                
Status colours
Green - ready.
Yellow - usable, but worth checking.
Red - fix before applying changes.

                
Images
Images are never compressed automatically. Files over 4 MB are flagged so you can reduce them individually if useful.
Use the Used / Unused switch to keep a file in the project without showing it on the public map. Reduced images stay temporary until you apply the final changes.

                
Excel imports
The manager ignores the Image column and everything after it. Existing matches are merged and their photos are kept.
An import only stops after five consecutive empty rows.

                
Map editor
Use + / − or Ctrl + scroll to zoom. Country Codes shows a human-facing province/state abbreviation; Numbers shows the exact SVG region ID. Drag the background to pan or a marker to move it.
